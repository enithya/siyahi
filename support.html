Privacy Support

Support

Write to support@enithya.com. We cannot see your journal from here — it never leaves the device unless you export a copy.

Forgot pin

If you set a recovery word when you turned the lock on, use Forgot pin on the lock screen and enter that word. Then set a new pin in Settings.

If both the pin and the recovery word are gone, there is no email reset. The lock screen lets you type ERASE to wipe this device copy. A JSON file you exported earlier can be restored after that.

Backup

Settings → save a copy. Keep that file somewhere you will find it. Restore picks the same kind of file.

Closed months

Months before the current calendar month are closed. You can still add a line there; Siyahi will show how later balances change and wait for you to confirm. You cannot date a line before the month you started this book.

Recurring

Templates never post on their own. Log this month when it actually happened.
